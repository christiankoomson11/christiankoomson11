### What I'm building

**[Reconciliation Engine](https://github.com/christiankoomson11/ReconciliationEngine)**
A Java/Spring Boot REST API that compares two sets of financial transactions and reports discrepancies, with configurable tolerance for rounding differences. Fully tested (JUnit + MockMvc), with a detailed design log covering every architectural decision — and the bugs along the way.

**[Manchester Transport Map](https://github.com/christiankoomson11/ManchesterTransportMap)**
A real-time visualisation of Manchester's bus network, parsing live SIRI-VM data from the UK Bus Open Data Service and rendering hundreds of moving buses on an interactive map with a 2-second refresh rate.

**[Resolve](https://resolve-student-support.vercel.app/)**
A student issue-management platform built for a Computing & Engineering department hackathon — students submit issues, administrators track them through to resolution. Led a 4-person team through the build using Scrum.
